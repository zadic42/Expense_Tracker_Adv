# 💰 Expense Tracker Frontend

A modern and responsive Expense Tracker web application that helps users manage their daily income and expenses with a clean dashboard and intuitive user interface.


---

## 📌 Features

- 🔐 User authentication (Login / Signup)
- ➕ Add income and expense entries
- 📝 Edit and delete transactions
- 📊 Dashboard showing totals and balance
- 📅 Track spending history
- 📱 Fully responsive design
- ⚡ Fast and clean UI experience

---

## 🛠 Tech Stack

**Frontend**
- React.js
- JavaScript (ES6+)
- Tailwind
- Axios / Fetch API

**Backend**
- Node.js / Express / MongoDB

**Deployment**
- Render
